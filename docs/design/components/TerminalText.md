Terminal text is the default color scheme for output in a terminal pane, "Holonet Dark".

- Pane background is `terminal`, one step darker than the page, with the host's group color as a 2px top edge.
- Output is `ink-soft`; the command the person typed is `ink`.
- The prompt shows `user@host` in the host's group color at weight 500, then the path in `ink-soft`, with punctuation in `ink-dim`.
- Labels, timestamps and separators are `ink-dim`. Success words are `group-mint`, numbers such as PIDs are `group-violet`, paths and branch names are `accent`, warnings are `warn`.
- The cursor is a solid `ink` block that blinks, unless the person chose a bar or underline in Settings or asked the system for reduced motion.

Text is the `mono` style: 13px at 1.6 line height by default. The app renders it in JetBrainsMono Nerd Font; this preview uses JetBrains Mono.
